## RimWorld mods

These are my RimWorld mods, for anyone that doesn't use the Steam Workshop or wants to change them.
They are all CC0 unless the mod says otherwise, you can do whatever you want with them, no need to give credits.

To use one, open the mod, go to Releases, download the zip and extract it into your RimWorld/Mods folder.

- [NoTainted](https://github.com/purpleorangegames/RimworldNoTainted) - skips the tainted flag when pawns die ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=2004935468))
- [NoReddishBodies](https://github.com/purpleorangegames/NoReddishBodies) - removes the reddish tint on dark skin ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3217235349))
- [ColorblindMinerals](https://github.com/purpleorangegames/ColorblindMinerals) - different colors for minerals so they are easier to see ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=1424338139))
- [JustPassionSkillIcons](https://github.com/purpleorangegames/JustPassionSkillIcons) - new passion icons ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3215203476))
- [JustFloorTiles](https://github.com/purpleorangegames/JustFloorTiles) - floor retexture ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3193619828))
- [JustWoodFloor](https://github.com/purpleorangegames/JustWoodFloor) - wood floor retexture ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3189695842))
- [JustStoneTile](https://github.com/purpleorangegames/JustStoneTile) - stone tile retexture ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3189952629))
- [JustWalls](https://github.com/purpleorangegames/JustWalls) - wall retexture ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3204284370))
- [JustStorytellers](https://github.com/purpleorangegames/JustStorytellers) - storyteller retexture ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3217699484))
- [FemaleBodyVariants](https://github.com/purpleorangegames/FemaleBodyVariants) - female textures for thin, fat and hulk bodies ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3207125987))
- [FemaleApparelVariants](https://github.com/purpleorangegames/FemaleApparelVariants) - female apparel textures for those bodies ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3511966169))
- [JustBodies](https://github.com/purpleorangegames/JustBodies) - female body textures based on Beautiful Bodies ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3215805750))
- [FloraReskinPatchOnly](https://github.com/purpleorangegames/FloraReskinPatchOnly) - patch for cattleya's Flora Reskin, uses the textures from pashka's Flora reskin HD ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3190366420))
- [ReShadeForRimWorld](https://github.com/purpleorangegames/ReShadeForRimWorld) - loads ReShade shaders in RimWorld 1.7, works on native Linux, BSD license like ReShade ([Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3826441547))
